# FHL Image Studio V2.0.3.1 macOS Acceptance Report

Status: macOS Apple Silicon patch release prepared and verified on 2026-07-28. GitHub upload remains pending owner review.

## Scope

- This patch fixes FHL Images configuration-state refresh and macOS right-click paste in API Key fields.
- It preserves all V2.0.3 features and does not change or publish the Windows package.
- Target: Apple Silicon (`darwin/arm64`), macOS 13 or newer.
- Release assets are additive and use tag/version `v2.0.3.1`; the existing `v2.0.3` Release is not deleted or overwritten.

## Release Assets

- `FHL-Image-Studio-Desktop-V2.0.3.1-macOS-AppleSilicon.dmg`
- `FHL-Image-Studio-Desktop-V2.0.3.1-Source.zip`
- `SHA256SUMS.txt`

The DMG contains `FHL Studio.app`, an Applications alias, the Codex Skill installer, macOS documentation, and the arm64 CLI. The source ZIP is generated from the committed Git tree and is checked before compression.

## Toolchain

- Node `24.14.0` / npm `11.9.0`
- Go `1.26.5` (`darwin/arm64`, `GOTOOLCHAIN=local`)

The Wails CLI download timed out during this local build, so the release script used its supported direct bundle build against the pinned Wails module. The app bundle was then assembled, signed, and verified by the same release script.

## Default Settings and Data Safety

- The distributable does not contain a configured API Key. `config/cli.env.example` keeps `IMAGE_STUDIO_API_KEY` empty.
- Source-package validation excludes local configuration, Keychain data, WebKit state, history databases, generated images, imported test images, raw responses, logs, caches, and temporary files.
- `node_modules`, frontend `dist`, `build/bin`, release assets, Mach-O binaries, and local build tools are excluded from the source ZIP.
- Preparing this release does not clear or modify the developer Mac's installed-app settings, Keychain credentials, or history.

## Manual Verification

- The owner verified one-click API configuration, connection-state refresh, and image generation after the fix.
- The owner verified right-click paste in the production API Key input.
- The owner verified replacement installation and retained local data behavior on the development Mac.

## Distribution Limitations

- The app is ad-hoc signed and not Apple-notarized because no Apple Developer signing identity is configured. Gatekeeper assessment therefore reports rejected even though the bundle signature and DMG integrity pass.
- On first launch, users must open the app from Finder with right-click **Open** and confirm the system prompt.
- Intel Mac, Mac App Store, automatic updates, and a clean-machine macOS 13 acceptance run are outside this patch release.
