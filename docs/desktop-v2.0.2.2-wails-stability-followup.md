# Desktop V2.0.2.2 Wails 便携稳定化续作

## 版本策略

- 本目录是 `V2.0.2.2` 开发轨道，不是对外发布版本。
- 当前产品、CLI、Skill、EXE 和测试包版本继续维持 `V2.0.2.1`。
- 所有功能、性能和打包回归通过后，再一次性升级为 `V2.0.3`。

## 已完成基线

- 正式用户入口继续是 Wails 独立窗口；`9230` 仅作为 Codex 和自动化测试入口。
- 外部图片导入、参考图、批量图、历史图和结果图优先使用受管媒体路径，而不是直接依赖外部原始路径。
- `BatchResultGrid` 的参考图悬浮预览会在旧 `/media/preview/...` 地址失效时读取受管路径并回退到 data URL。
- 打包版 E2E 支持 `--e2e-only --e2e-port 9230`，并提供批量目录、`Smoke 10`、`Preview grid`、大图预览和失效媒体 fallback 的测试入口。

## 后续优化原则

1. 所有涉及图片路径、媒体注册、批量选择、参考图或大图预览的修改，必须先验证源码，再验证重新打包后的 Wails EXE。
2. 打包版验证以 `9230` 自动化为主，至少覆盖：导入参考图、双击参考图、直接加入多张、批量目录导入、悬浮参考图、双击结果图和失效媒体回退。
3. 不允许用“源码 Vite 正常”作为 Wails 发布包正确的唯一依据。
4. 每次测试完成后清理便携测试包的 `input/`、`output/`、`intermediate/` 和 WebView 测试状态；发布前再次执行独立干净包验证。

## 最终 V2.0.3 验收

- 源码构建、Go 测试、前端测试和 Wails 打包通过。
- 打包版在新目录运行，不依赖开发机外部图片原路径。
- Codex E2E 和人工桌面窗口均完成路径、批量和预览回归。
- `image-cli.cmd --status --json` 不显示 API Key。
- 发布包不包含 `config/cli.env.local`、`config/webview/`、测试图片、输出、日志或本机缓存。
