# Windows V2.0.4 通用局部编辑往返

## 批次目标

把现有全景局部编辑能力扩展为普通图片可用的局部编辑往返，同时保留 360 全景模式。普通图片按“选择区域、创建裁切副本、编辑或导入、对齐、贴回原图”运行；原图历史项不被覆盖。

## 修改范围

- Windows V2.0.4 前端类型、历史/工作区持久化和 Store 动作。
- 新增平面局部贴回核心，使用原图自然像素坐标。
- 现有全景对齐器增加普通图片分支，保留球面贴回算法。
- 工具栏、画布快捷操作、历史栏、时间线和结果详情增加入口。
- 本批未修改 Android、V2.0.3、发布附件、API/Profile 或后端协议。

## 实现结果

- `LocalEditRoundtripRef` 以 `planar` / `panorama` 联合类型保存往返元数据；旧 `panoramaRoundtrip` 历史继续兼容。
- 普通图片工具栏“局部编辑”使用已选矩形；没有矩形时自动切换标注工具并提示框选。
- 裁切动作创建独立历史子项，保留完整链路：原图、裁切副本、编辑/导入图、贴回结果。
- 平面贴回支持移动、缩放、旋转、任意外部比例、蒙版、羽化、亮度、对比度和色相调整。
- 贴回结果为终态历史项，不再携带可重复贴回入口；全景终态行为不变。
- 原图自然尺寸用于裁切和合成；预检限制为单边 16,384 像素、64 MP，估算工作内存超过约 768 MB 时提前阻止。
- 画布、历史栏、时间线、结果详情均可打开普通图片手动对齐器；对齐器内可导入 PNG/JPG/WebP 外部编辑图。

## 风险与限制

- 本批未使用真实超大相机文件和真实 Wails 桌面数据做人工贴回验收；核心算法和 Store/UI 契约已自动化覆盖。
- 64 MP / 768 MB 保护值是 Windows 浏览器/Wails 的保守默认值，后续可基于实际设备反馈单独调整。
- Vite 构建仍有既有动态导入和大 chunk 提示，不是本批新增错误。
