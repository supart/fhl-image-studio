## 根因

参考图动作原来只更新顶层 `sources`，当前 workspace 快照仍保留旧列表。添加图片、自动比例同步、切换分辨率和刷新恢复读取快照后，会把已经删除的引用重新写回。

浏览器代理物化虚拟图片时还可能在异步完成后用发起时的完整数组覆盖实时列表。用户在等待期间删除或排序参考图，就会遇到同样的复活问题。

局部贴回的另一类风险是大图路径回退到浏览器整图 Canvas，或者把编辑图尺寸误当成物理覆盖范围。这样 2K 编辑结果会覆盖超出镜头框的原图区域，且高分辨率源图会产生不必要的 Base64/内存峰值。

## 实现结果

### workspace 状态

- `studioStore.images.ts` 的删除、清空、排序、选择、导入和历史参数动作都捕获目标 `workspaceId`，使用函数式状态补丁同步 workspace 快照和活动标签镜像。
- 异步导入完成时重新读取目标 workspace 的实时 `sources`，追加或替换只作用于仍有效的目标；用户已删除的其他图片不会被旧快照带回。
- `studioStore.ts` 的浏览器代理物化、批处理物化和全景元数据恢复改为按路径合并到实时列表，保留用户当前顺序和删除结果。
- 失败任务的“应用参数（不生成）”同步写入当前 workspace，切换分辨率或标签后不会恢复失败任务的旧参考图。
- 新增 workspace/UI/静态合同测试，覆盖删除最后一张仍保持图生图、清空、排序、分辨率切换、标签切换、刷新恢复和延迟导入竞态。

### 高清平面贴回

- Windows `PasteLocalEdit` 先用 `image.DecodeConfig` 读取尺寸，再进行门禁；原图上限 `100MP / 16,384px`，编辑图和蒙版上限 `64MP / 16,384px`。
- 预检裁切矩形、蒙版尺寸和约 `768MiB` 工作内存估算，超限在完整解码和分配前返回；失败时删除临时输出，不创建历史半成品。
- 通过惰性 `planarCompositeImage` 按采样编码完整尺寸 PNG，不再额外分配整张输出 RGBA；原图文件不覆盖。
- `cropRect` 的自然像素坐标始终是物理贴回范围。编辑图无论是 1K、2K 还是任意比例，都只被双线性采样到该范围；裁切外像素保持原值。
- 普通图前端对旧记录的裁切矩形做尺寸和边界归一化；源图超过 `64MP` 时继续走桌面磁盘路径，禁止整图浏览器 Base64/Canvas 回退。

### 360 规则复用与文案

- 平面路径复用 360 `panorama/core.ts` 的蒙版 Alpha 采样和 smoothstep 羽化函数；现有球面投影、镜头控制和全景历史兼容逻辑不重写。
- 局部编辑菜单文案统一为“裁切局部重绘”，已保存旧历史文本不迁移、不改写。

## Codex 浏览器隔离验收

测试使用独立本地端口 `http://127.0.0.1:5174/` 和独立存储实例 `qa-reference-slot-20260819`，未读取或修改用户主端口工作区。临时 PNG 由本机生成并在系统 Temp 目录使用。

验收顺序及结果：

1. 导入两张参考图，删除第一张；界面和 workspace 只保留第二张。
2. 添加第三张；列表只显示第二、第三张，第一张没有重新出现。
3. 依次切换 `1K -> 2K -> 4K -> 1K`；每个分辨率下仍为第二、第三张。
4. 新建第二个标签再切回第一个；删除状态保持。
5. 刷新页面恢复 workspace；删除状态和两张剩余参考图保持。
6. 清空两张后重新添加一张；旧路径不出现，最终显示 `参考图 1 张`。
7. 视口 `1252x930`、`1440x900`、`1024x768` 均通过：`document.documentElement.scrollWidth` 等于视口宽度，页面无横向溢出。

页面控制台新增 warning/error 为 `0`。没有在隔离验收中提交生图、重试任务或调用真实/付费 API。

## Windows 桌面高清验收

为避免接触用户私人照片，使用本机临时目录生成的非透明 JPEG 夹具模拟相机大图；Sony/哈苏 EXIF 字段读取入口沿用上一批已验证实现，本批不导入 RAW（ARW/3FR）。

| 场景 | 结果 |
| --- | --- |
| `10000x8500`（85MP）源图，`2048x2048` 编辑图，裁切 `x=1000,y=2000,w=3000,h=2000` | 约 `11.05s` 完成；输出 `10000x8500`；裁切中心发生变化；裁切外 3 个采样点保持；源文件 SHA-256 未变化；输出约 `268,964` bytes |
| `12000x8500`（102MP）源图 | `7ms` 内由 `DecodeConfig` 尺寸门禁拒绝：`原图尺寸 12000x8500 超过桌面贴回上限`；未进入完整解码 |

输出失败、超限和取消路径均由服务层在返回前清理临时输出；本次夹具输出只位于 Temp/隔离根目录。
