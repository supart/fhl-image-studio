# Windows V2.0.4 参考图卡槽交互优化

## 目标与边界

- 仅修改 Windows V2.0.4 参考图卡槽；覆盖普通图生图和批处理固定参考图，不改变批量输入队列、生成协议、存储结构或 Android。
- 卡槽完整显示输入图像，悬浮快速查看，双击才进入画布大图；右键提供复制、粘贴追加、替换和删除。
- 全程只使用离线合成图片，不点击生成、连接测试、提示词调用、失败重试或其他付费路径。

## 卡槽与预览

- Windows 卡槽保持 `56px` 高，宽度按图片尺寸或加载后的自然尺寸计算并限制在 `36-112px`；`16:9`、方图和竖图分别显示为约 `100x56`、`56x56`、`36x56`。
- 图片使用 `object-fit: contain` 完整显示；加号仍固定为 `56x56`，不修改 `SourceImage` 或持久化数据。
- 鼠标停留 250ms 后通过 Portal 显示最大 `360x280` 的原比例预览，自动限制在视口内；离开、拖拽、右键、双击、图片变化和卸载都会关闭。
- 代码复核后用浏览器读取最终计算样式，发现旧 `.source-thumb img` 规则仍覆盖组件类名并计算为 `cover`；增加 Windows 卡槽专用高优先级规则后复验为 `contain`，同时增加样式合同防止回归。

## 点击与右键操作

- 普通状态单击不执行操作；存在可用对比图时，单击延迟 220ms 切换，双击会取消待执行单击并只打开一次参考图大图。
- 卡槽增加可访问名称与键盘焦点，`Enter` 使用与双击相同的大图入口；删除按钮、右键和拖拽不会触发单击或双击。
- 普通加号和批处理固定参考图加号右键均提供“粘贴图像”；卡槽右键提供“复制图像 / 粘贴替换当前格 / 删除参考图”。
- 剪贴板读取首个 PNG、JPEG 或 WebP；复制会从内存、虚拟图或磁盘原图读取完整内容并统一写为 PNG，不使用缩略图。
- 替换通过原 `path` 定位，保持槽位和总数；目标被异步删除或新路径与其他槽重复时拒绝写回。错误和 Toast 不包含图片 Base64、本地路径或剪贴板内容。

- 剪贴板覆盖 PNG/JPEG/WebP、空内容、不支持格式、权限拒绝、复制成功/失败以及非敏感错误映射。
- UI 覆盖悬浮延迟与关闭、单击/双击隔离、普通与批处理右键入口、复制、替换和删除；样式合同锁定 Windows 最终 `contain` 优先级。
- 最终 CSS 优先级修复后，定向 Node `6/6` 与相关 UI `14/14` 通过；全量 TypeScript、Lint `0/58`、Node `625/625`、UI `90/90` 和 Windows 前端构建 1,976 modules 通过。

## Codex 浏览器验收

- 端口 `127.0.0.1:5173` 已确认来自当前 V2.0.4 源码；活动版本显示 `V2.0.4`。
- 使用离线 `320x180`、`180x180`、`120x200` 图片真实执行普通加号右键粘贴、悬浮、单击、双击、复制后再粘贴、方图替换和删除。
- 初次三槽实测为 `100x56`、`56x56`、`36x56`，悬浮层约 `360x210` 且在视口内；替换保持槽数和顺序，复制剪贴板类型为 `image/png`。
- 批处理开启后，固定参考图加号右键粘贴使参考图从 3 张增至 4 张，证明批处理入口复用同一导入链；随后逐项通过右键删除恢复。
- `1920x1080`、`1440x900`、`1024x768` 的页面横向溢出均为 0，卡槽和右键菜单完整在视口内；1024 档额外验证设置和 360 弹窗边界、滚动与关闭。
- 对比按钮因当前用户结果为文生图记录而禁用，无法安全建立真实对比图；单击延迟和双击取消由 UI 行为测试覆盖，没有篡改 Store 或用户历史伪造结果。
- 最终恢复 `1239x930`、文生图、批处理关闭和参考图 0；API 十槽仍显示已配置，现有 24 项历史未修改。
