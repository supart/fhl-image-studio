# Windows V2.0.4 标注移动与变形撤销步骤

## 本批目标

修复标注工具后退/前进只回退新建或删除、跳过移动和变形的问题。撤销粒度固定为一次完整鼠标/触控手势一个步骤。

## 根因

指针移动、变形句柄、批注标签拖动和文字提交原先调用无历史的 `updateAnnotation()`。拖动过程又会连续产生多次 pointer move，不能直接让每次 `updateAnnotation()` 都写入撤销栈，否则会堆积中间帧。

## 实际修改

- `StudioState` 新增 `commitAnnotationUpdate(id, before, after, label?)`；`updateAnnotation()` 继续只更新拖动预览。
- 新增 `features/annotation/annotationHistory.ts` 纯函数，深复制自由画点等数组，生成可逆的前后快照；空变化不会入栈，新提交清空 redo 栈。
- `useAnnotationInteractions` 在 pointer down/文字编辑开始时保存原始对象，在 pointer up、变形结束、标签拖动结束和文字提交时各写入一个历史步骤。
- 交互层增加 `annotationsRef` 读取最新 Store 对象，避免 React 事件闭包在批量 pointer move 后提交旧快照。
- 新建对象仍是独立步骤，因此历史可按“新建 → 移动 → 变形 → 标签/文字修改”逐步后退和前进；取消会话快照、工作区隔离、合成和 Output 流程保持不变。
