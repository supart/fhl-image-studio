## 实现结果

- `scripts/dev-setup.ps1` 幂等配置 `.githooks`、`pull.ff=only`、提交模板和无 upstream 的本地优先策略，并检查 V2.0.4 基线。
- `scripts/dev-check.ps1` 提供 Fast、Batch、Milestone 三层离线检查；暂存区敏感/生成文件会被拒绝。
- `scripts/archive-v2.0.4.ps1` 从干净且已验证标签生成 Git bundle、跟踪源码 ZIP、SHA-256 清单和中文恢复说明。
- `scripts/doctor.ps1` 改为允许指定的只读 `origin`，同时检查无 upstream、无 pushurl、敏感文件和可选干净工作树。
- `.githooks/pre-push` 默认阻止推送，只有显式授权变量存在时才会执行 Batch 检查。
