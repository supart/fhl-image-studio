# Windows V2.0.4 标注画布底部浮动操作栏

## 本批目标

在普通图像标注模式的画布底部中央增加与局部编辑工作台一致的浮动操作栏，统一提供后退、前进、删除、确认标注和取消入口。

## 实际修改

- 新增 `frontend/src/features/annotation/AnnotationActionBar.tsx`，使用 Lucide 图标、稳定按钮尺寸、无障碍标签和合成忙碌禁用态。
- `CanvasStage` 增加相对 `.stage-host` 的 portal 容器；浮窗仅在有图片、标注模式且未打开结果网格/历史画廊时显示，按钮事件不会穿透到 Konva 画布。
- `Toolbar` 复用现有 `undo`、`redo`、选中对象 `removeAnnotation` 和 `confirmAnnotationComposite("strict")`；顶部确认按钮保留，底部确认与其共享越界弹窗和忙碌状态。
- `studioStore.annotations.ts` 增加按 `workspaceId + currentImage.id` 隔离的内存标注会话快照。取消时恢复标注、选中对象和撤销/重做栈，清除临时 `annotationSource`，不创建 Output、历史或参考图；确认成功后清理快照。
- “取消”在本轮有标注改动时使用浏览器二次确认；无改动直接退出。删除只处理当前选中对象，未选中时禁用。
- 未修改 Android、V2.0.3、Cowart 源码、用户图片、API 凭据、确认合成和真实生图链路。
