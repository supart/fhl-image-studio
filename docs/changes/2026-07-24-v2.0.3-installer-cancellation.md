# V2.0.3 Installer Cancellation

## Decision

V2.0.3 取消 Windows 安装器产品。项目继续以 AGPLv3 开源源码为主体，Windows 只维护一个预编译交付：Portable ZIP 免安装包。

该决策覆盖同日较早的 NSIS 安装器实现和验收结论。历史记录保留并明确标记为已取消，不能再把 Setup 当作当前发布产物。

## Removed

- 删除 NSIS `project.nsi` 模板和 `package-windows-installer-v2.0.3.ps1` 打包脚本。
- Release workflow 删除 NSIS 安装、Setup 构建及 Setup/哈希/manifest 上传步骤。
- 删除安装器专属契约测试，并增加“Release 不得重新引入安装器工具链”的负向测试。
- README、构建文档、项目结构、使用说明、故障排查、CHANGELOG、发布说明和验收报告统一改为源码 + Portable 定位。
- 从本地 `发布附件` 精确删除先前生成的 Setup EXE、SHA-256 sidecar 和 manifest；Portable ZIP 与源码包未在该清理步骤中删除。
- `image-cli.cmd` 删除注册表、`Program Files` 和安装版 AppData 分支，源码与 Portable 均使用包根目录和显式 `IMAGE_STUDIO_PUBLIC_ROOT` 覆盖。

## Retained

- `package-windows-portable-v2.0.3.ps1`、Portable 启动器、干净源码脚本和发布安全扫描继续保留。
- GUI 到 CLI 的 Wails `SyncCLIConfig` 桥接继续保留，因为打包后的 Portable 依赖它同步当前 API profile。
- 非 Portable 的 Wails 源码直构仍保留用户配置目录回退，但它不是安装产品或发布形态。
- API Key 仍不进入源码、Portable、文档、日志或前端持久化状态。

- 发布与 CLI 聚焦测试通过：前端 7/7，桌面 Go 聚焦测试通过。
- 前端 typecheck 通过；lint 为既有基线 `0 errors / 63 warnings`；Node 通过 `550/550`；UI 通过 `12/12`；Windows 生产构建通过。
- 桌面和 Go CLI 的 `go test ./...`、`go vet ./...` 均通过；Worker 通过 `5/5`。
- Wails Windows x64 构建、Portable 重建和干净源码重建均通过；Portable、ZIP 和源码安全/合规扫描均为 `0 issues`。
- 当前 Portable、干净源码和 `发布附件` 中不存在 `.nsi`、安装器打包脚本或 Setup 附件；包内 CLI 不含注册表、`Program Files` 或 AppData 安装分支。
