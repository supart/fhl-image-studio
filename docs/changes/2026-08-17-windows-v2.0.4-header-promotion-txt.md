# Windows V2.0.4 顶栏推广信息 TXT 配置化

## 目标与边界

- 只把 Windows 顶栏公告、复制群号和注册按钮改为根目录 TXT 配置；品牌、版本、API 控件、FHL 配置弹窗、Android 和 Mac 均不改变。
- 开发版从源码根目录读取 `顶部推广信息.txt`，Portable 从 EXE 同级读取；刷新开发页面或重启软件生效，不增加文件监听或设置入口。
- 文件缺失、空白、仅注释、超限或读取失败时完整隐藏推广区，不回退任何内置文案。

## 实现

- 新增纯解析器和只读加载器，支持 UTF-8 BOM、CRLF/LF、空行、`#` 注释、首个等号分隔和重复键后值覆盖；未知键忽略。
- `群公告`、`群号` 独立显示；`注册文案` 和合法 HTTP(S) `注册链接` 同时存在才显示注册按钮。文件上限 16 KiB，各字段另有限长，异常字段单独隐藏。
- Windows 顶栏推广区拆为独立组件，复制内容、注册链接、Toast 和可访问名称均使用运行时配置；加载期间和失败时不占布局空间。
- Vite 与 Wails 新增固定 `GET/HEAD /__image-studio-files/header-promotion`，返回 `text/plain; charset=utf-8` 与 `Cache-Control: no-store`；其他方法返回 405，接口没有路径参数。
- Portable 与 release-source 脚本使用“存在则复制”，不会在用户删除文件后生成默认内容；README 和 Portable 使用说明补充编辑规则。

## 自动化

- 解析与加载覆盖 BOM、换行、注释、空值、重复键、非法行、未知键、非法 URL、字段/文件超限、缺失和读取失败。
- UI 覆盖完整配置、四字段独立删除、空配置、复制群号和注册链接传参；所有外部打开均为 Mock，没有访问网站。
- Vite 文件合同与 Go 路由覆盖正确根目录、缺失、空文件、超限、GET/HEAD、方法拒绝和非固定路径下放；打包合同锁定 Portable/release-source 只复制源 TXT。
- 前端 Node `609/609`、UI `67/67`、TypeScript、Lint `0/58`、Windows 构建 1,970 modules 通过。
- 桌面端 `go test . ./backend`、`go vet . ./backend`，CLI `go test ./...`、`go vet ./...`，Worker 语法与 `5/5` 测试通过。
- 版本漂移、gofmt、`git diff --check` 和 696 文件源码合规快照通过；合规临时目录验收后已删除。
