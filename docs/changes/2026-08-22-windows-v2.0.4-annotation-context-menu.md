# Windows V2.0.4 标注指针右键菜单

## 范围

修复指针模式右键直接删除标注的问题。右键命中标注后只选中并打开上下文菜单，删除必须明确选择“删除标注”；同时提供“复制标注”动作。空白处右键不创建、不删除对象。

## 实现

- `useAnnotationInteractions` 的右键处理改为回调命中标注 ID 和屏幕坐标，不再直接调用 `removeAnnotation()`；箭头文字标签也纳入右键命中范围。
- `CanvasStage` 复用现有 `ContextMenu`，提供“复制标注”和“删除标注”两个动作。
- “复制标注”调用 `cloneAnnotationForCopy()`，保留颜色、描边、字体、弯曲、标签位置和自由画点列，按图像自然像素偏移后通过现有 `addAnnotation()` 写入撤销栈并选中新副本。
- 复制偏移在靠近画布边缘时自动反向，无法安全偏移时保持原位，避免副本越出当前图像；删除动作继续复用现有撤销/重做语义。
