# Windows V2.0.4 设置默认值与持久化模块化

## 目标与边界

只迁移普通设置的默认值、存储键、读取校验、持久化动作和运行时应用逻辑。保持 `useStudioStore` 公共入口、原有 namespace、存储键、API/Profile/凭据数据、迁移标记和序列化格式不变；不提前迁移工作区、历史、素材、任务队列或 `host.ts`。

## 实现

- 新增 `state/studioStore.settings.ts`，集中维护主题、字号、内核运行模式、输出格式、代理模式和代理地址六项普通设置。
- 固定原有 namespaced localStorage 键，并统一合法值读取、非法值回退、字符串清理和默认存储值。
- 通过显式 `SettingsRuntime` 注入主题、字号和内核运行时副作用；纯设置策略模块不直接依赖 Wails、DOM 或 `host.ts`。
- `studioStore.ts` 的初始状态、普通 bootstrap、E2E bootstrap、预览 bootstrap、设置动作和应用初始化统一复用设置策略；`useStudioStore` 对组件的接口保持不变。
- `applicationStateReset.ts` 复用相同默认值与持久化值，不再维护第二套设置规则。
- 删除职责已合并的 `lib/proxy.ts`，源码和测试中不存在残余导入。
- 更新状态模块说明，并新增 Node 行为测试，锁定默认值、存储键、合法/非法读取、持久化副作用以及 API Profile 数据不被设置动作修改。
- 完整 UI 测试首次运行发现 `SettingsPanelPerformance` 的既有 host mock 缺少新显式运行时依赖；只补充 `setKernelRuntimeMode` mock 后从 UI 测试起点重跑通过。
