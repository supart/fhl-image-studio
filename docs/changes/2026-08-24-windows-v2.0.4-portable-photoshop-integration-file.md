# Windows V2.0.4 Portable Photoshop 对接文件

## 范围

本批只修改 Windows 桌面版 V2.0.4 开发源码的 Portable 打包流程。没有读取或修改 Photoshop 插件源码、V2.0.3 正式版、`FHL-PS-Bridge-Contract` 契约仓库、正式发布包或 Adobe External 旁载；没有启动真实 Provider，也没有调用真实或付费生图 API。

## 固定格式

Portable 根目录第一层由 `scripts/package-windows-portable.ps1` 自动写入固定文件名：

`FHL Studio Photoshop 对接文件.json`

机器可读字段固定为：

| 字段 | 值/语义 |
| --- | --- |
| `productId` | 固定 `fhl-image-studio-desktop` |
| `integrationFileFormatMajor` | 对接文件格式主版本，当前为 `1` |
| `psBridgeProtocolMajor` | Photoshop Bridge 协议主版本，当前为 `1` |
| `launchPath` | 包根目录内的相对 EXE 路径 |
| `displayName` | `FHL Studio 方汤圆版` |
| `desktopVersion` | 当前桌面版本，仅显示和诊断用途 |

实际 V2.0.4 样例：

```json
{
  "productId": "fhl-image-studio-desktop",
  "integrationFileFormatMajor": 1,
  "psBridgeProtocolMajor": 1,
  "launchPath": "FHL Studio 方汤圆版 V2.0.4.exe",
  "displayName": "FHL Studio 方汤圆版",
  "desktopVersion": "V2.0.4"
}
```

文件不承载 Bridge 地址、端口、Session、Profile、capabilities 状态或任何凭据。外部客户端仍必须通过当前桌面实例的 `GET /fhl-ps/v1/health`、`POST /fhl-ps/v1/session`、带 Bearer 的 `GET /fhl-ps/v1/profile` 和 capabilities 完成真实可用性判断。

## 生成与安全校验

打包脚本在复制精确命名的 Wails EXE 后调用 `scripts/portable-photoshop-integration.ps1`：

1. 构造固定六字段对象。
2. 校验产品标识和两个主版本均为 `1`。
3. 校验 `launchPath` 非空、非绝对路径、不含 `..` 段，解析结果仍在包根目录内，并且目标文件已经存在。
4. 以 UTF-8 JSON 写入 Portable 根目录第一层。

helper 还提供离线读取校验，拒绝缺失文件、非法 JSON、未知字段、错误产品标识、错误协议主版本和越界启动路径。`.fhl-studio-portable` 仍由原打包脚本独立创建，未被对接文件替代。

## 版本升级规则

V2.0.5、V2.1.0 保持文件名、字段名称、字段类型和基本语义不变，只允许更新 `desktopVersion` 和包内 `launchPath`。桌面版本号永远不能作为 Photoshop 插件兼容条件；协议兼容由 Bridge v1 health/session/profile/capability 握手决定。改变协议主版本时必须按独立契约治理新增 `/fhl-ps/v2`，不能修改该文件来隐式升级协议。
