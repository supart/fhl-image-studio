# Windows V2.0.4 恢复默认但保留 API

## 目标与边界

只初始化 `fhl-image-studio-desktop-dev` 的非 API 状态，完整保留开发环境已有 API Profile、活动项、URL、模型、FHL 文本、Images 池、RunningHub 配置、密钥提示和凭据。不得读取或显示完整 Key，不修改稳定 namespace、V2.0.3 迁移标记和磁盘图片，不调用生成、连接测试或提示词服务。

## 实现

- 新增 `resetApplicationStatePreservingAPI(): Promise<ResetSummary>`，返回清理数量、保留配置数量、默认项和不敏感警告。
- `applicationStateReset.ts` 以显式清单删除工作区会话、提示词历史、参数预设、素材组和界面偏好，普通设置写回系统主题、100% 字号、自动内核、PNG、系统代理、默认共享并发和默认输出目录；没有 `localStorage.clear()`。
- IndexedDB 历史使用结构化事务计数并清空 preview/full 两个 store；磁盘上的生成图片及 `input/output/intermediate` 不进入删除路径。
- API Profile、活动 Profile、浏览器/系统凭据、FHL 文本、Images 池、RunningHub、传输模式和迁移标记不进入清理清单，也不调用永久 API 清空函数。
- 活动门禁覆盖运行/排队、`submitting`、原生运行元数据、浏览器任务快照、连接测试、FHL 文本测试、提示词优化和图片反推；执行期间同时阻止提交、连接测试、提示词任务和连续池启动。
- 新增单次执行锁并清除旧工作区持久化、自动重试和临时并发计时器。应用状态 epoch 使重置前捕获的异步提交准备和浏览器终态同步失效；重置开始后的历史回调直接忽略。
- 启动、新建工作区与重置共用 `workspaceDefaults.ts`，减少空白工作区默认值漂移。
- 设置页新增独立入口和两阶段确认。取消默认聚焦并回到入口；执行期间禁用关闭和重复确认；成功摘要不包含 Key、令牌或 Key hint。
- 公共 Modal 补齐 `aria-labelledby`、关闭按钮语义和视口宽度上限。桌面 Modal 为 `max-width: calc(100vw - 40px)`；`<=640px` 时为 `calc(100vw - 24px)`，同时收紧 backdrop/body padding。
- 为初始化入口、取消、确认和完成按钮补充组件级字号与内边距，避免全局 button reset 覆盖 Tailwind 工具类后出现视觉挤压。
