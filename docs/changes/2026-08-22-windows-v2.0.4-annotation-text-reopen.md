# Windows V2.0.4 标注文字双击编辑与确认保留

## 根因

- 指针模式原先单击标注就打开编辑框，不符合“先选中、双击编辑”的操作预期。
- Stage 的双击缩放事件会在标注对象双击后继续执行，导致视图缩放跳变，文字按自然像素渲染后容易被误认为消失。
- 文字提交没有在 blur/确认边界显式读取 textarea 的最新 DOM 值，且提交基线可能被并发的对象快照更新判定为过期。

## 修改

- `AnnotationShape` / `AnnotationLayer` 增加双击激活回调；单击仅选中，指针模式双击文字或批注箭头才打开编辑框。
- `CanvasStage` 仅允许图片或空白 Stage 触发 fit/100% 双击缩放；标注双击由 annotation 模块独占。Android 不传入激活回调，保持原有行为。
- `AnnotationTextEditor` 的确认和快捷键提交前读取 textarea 当前值；`useAnnotationInteractions` 的 blur 提交同步最新草稿，并以当前对象快照作为文字撤销基线。
