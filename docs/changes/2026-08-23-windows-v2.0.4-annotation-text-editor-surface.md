# Windows V2.0.4 标注文字共享编辑面板

## 目标

普通“文字”标注的输入区域在复杂画布背景上容易被看成透明浮层。本批让普通文字和批注箭头明确复用同一个不透明编辑面板，保证编辑期间文字、边框和确认入口始终可读。

## 修改范围

- `frontend/src/features/annotation/AnnotationTextEditor.tsx`
  - 增加 `annotation-text-editor` 面板类和 `annotation-text-editor-input` 输入框类。
  - 保留 textarea 的自然像素字号换算、最新草稿提交、Escape 取消、Ctrl/Cmd+Enter 提交和画布内“确认文字”按钮。
- `frontend/src/styles/_canvas.css`
  - 浅色主题使用 `rgb(255 255 255 / 0.98)` 面板和实体白色输入框。
  - 深色主题使用 `rgb(15 23 42 / 0.98)` 面板和 `rgb(30 41 59)` 输入框。
  - 增加边框、圆角、阴影、轻度 backdrop blur 及窄窗口最大宽度约束；用高优先级覆盖全局 textarea 透明背景规则。
- UI/Node 合同测试锁定两个类名和确认按钮存在。

普通文字和批注箭头仍由 `CanvasStage` 统一挂载 `AnnotationTextEditor`，没有引入第二套编辑器、画布、状态或持久化系统。
