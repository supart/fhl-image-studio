# Windows V2.0.4 FHL 文本模型拉取按钮显眼化

## 范围

只调整独立 `FHL 文本 API` 配置区的现有模型拉取入口。模型接口、凭据读取、列表清洗、模型选择持久化、提示词优化、图片反推和 Photoshop Bridge 请求链路均未修改。

## 修改

- 未保存模型设置时统一默认 `gpt-5.6-sol`，不再因电脑已有 FHL 文本 Key 而首次回退到 `gpt-5.5`；已保存的用户选择不覆盖，`gpt-5.5` 仍可手动选择。
- 将模型拉取按钮移到模型下拉框右侧，显示为蓝色描边“拉取模型列表”。
- 删除底部重复的灰色入口；底部只保留 Base URL、当前模型和“保存并测试文本 API”。
- 继续复用现有加载、禁用、成功和失败状态；获取失败不清空当前模型。
- 保留 `aria-label="获取 FHL 文本模型"`、`title` 和 `data-testid="fhl-text-fetch-models"`，并用 UI 测试锁定只有一个入口。
