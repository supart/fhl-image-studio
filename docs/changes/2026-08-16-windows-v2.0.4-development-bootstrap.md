# Windows V2.0.4 开发工作区初始化

## 初始化内容

- 新建外层 `V2.0.4-开发版`，保持历史开发版的“开发整合包”组织方式。
- 只保留 `源码`、`包开发版`、`发布附件` 和 `release-source` 四个用途明确的目录。
- 从正式标签克隆源码并保留 Git 历史，没有复制 V2.0.3 外层归档。
- 保留 Git 跟踪的 README、旧发布说明、验收报告、专题文档和 `docs/changes` 历史。
- 新增外层开发入口、目录说明和项目日志索引。
- 更新当前源码的开发约束、交接断点和 V2.0.4 开发中 CHANGELOG 入口。

## 明确排除

- V2.0.3 的发布版、发布附件、验收与发布现场、私人开发现场封存。
- `node_modules`、已有 `frontend/dist`、`build/bin`、EXE、ZIP 和旧运行时二进制。
- API Key、`cli.env.local`、其他 `*.local`、`config/webview` 和 Credential Manager 内容。
- 用户输入、生成图片、缩略图、中间图片、原始上游响应、浏览器任务日志和测试截图。
- 历史结构中用途重复的 `测试打包`、`release-assets` 与 `github-release`。

## 版本策略

开发目录和分支以 V2.0.4 命名，但当前程序、CLI、EXE、Portable 和脚本继续使用已验证的 `V2.0.3` 身份。进入正式封板批次后再统一执行版本升级，避免开发期把尚未验收的产物误认为 V2.0.4 正式版。
