# V2.0.3 Windows Installer

> Historical record only. On 2026-07-24 the maintainer cancelled the Windows
> installer product before release. The NSIS source, packaging script,
> workflow steps, Setup artifacts, and current product documentation were
> removed. See `2026-07-24-v2.0.3-installer-cancellation.md`.

Date: 2026-07-24

## Scope

- Added the primary x64 NSIS delivery artifact:
  `FHL-Studio-V2.0.3-Windows-Setup.exe`.
- Kept the accepted Portable ZIP unchanged and did not touch the archived
  V2.0.2.1 tree.
- No paid image request or API connectivity request was performed.

## Implementation

- Added a Unicode Simplified Chinese/English NSIS installer with Windows 10/11
  AMD64 checks, admin installation, selectable directory, license/progress/
  finish pages, WebView2 detection, shortcuts, repair install, and standard
  uninstall metadata.
- The clean payload contains the desktop EXE, CLI runtime and entry script,
  Codex Skill and manual installer, README, changelog, release notes, license,
  notice, and compliance documents.
- The installer rejects portable/user-data directories and never packages
  `.fhl-studio-portable`, `input`, `output`, `intermediate`, `config`, WebView
  data, logs, images, local configuration, or credential-like text.
- Added installed-mode `SyncCLIConfig` support and updated `image-cli.cmd` to
  use the HKCU data root plus `%APPDATA%\fhl-studio`. A QA finding corrected
  missing trailing-root normalization before the final artifact was built.
- Codex Skill installation remains an explicit current-user action from the
  Start Menu. Uninstall only removes the versioned Skill when its
  `PACKAGE_ROOT.txt` matches the current installation.
- Added optional Authenticode parameters and NSIS finalization hooks for a
  future certificate. The V2.0.3 test artifact is intentionally unsigned.
- Updated the future `v2.0.3` release workflow to publish Setup, SHA-256, and
  payload manifest beside the Portable ZIP. No GitHub Release was triggered.
