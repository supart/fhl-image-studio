# Windows V2.0.4 快速配置批量 API 入口修复

## 根因

桌面快速配置弹窗复用了 `FHLDesktopAPIConfig`，但没有传递 `bulkPasteOpen` 和 `onBulkPasteOpenChange`。`FHLImagesPoolConfig` 以回调是否存在作为批量按钮和批量粘贴弹窗的渲染条件，因此快速配置入口只显示十个槽位，不显示“批量配置 10 个 API”。普通 `UpstreamConfigModal` 入口原本已正确传递回调。

## 实现

- 在 `DesktopFHLQuickConfigModal` 内增加会话级 `bulkPasteOpen` 状态。
- 将状态和更新回调传给现有 `FHLDesktopAPIConfig`，复用既有批量解析、预填和保存流程。
- 快速配置关闭、切换高级配置和 `open=false` 时清理状态，避免批量弹窗在下次打开时残留。
- Android `LegacyFHLQuickConfigModal`、CLI、Bridge、凭据和 Images 池业务逻辑保持不变。
