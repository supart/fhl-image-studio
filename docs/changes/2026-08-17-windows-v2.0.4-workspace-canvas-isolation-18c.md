# Windows V2.0.4 工作区画布与关闭隔离（批次 18C）

## 目标

- 将蒙版、标注、对比、缩放、工具和撤销栈从全局运行态改为每标签独立运行态。
- 切换标签时恢复各自画布上下文，关闭标签时释放对应内存，软件重启后不恢复临时画布状态。
- 活动标签关闭前明确确认，并保证取消只影响目标标签。

## 实现

- 新增按 `workspaceId` 管理的 `workspaceCanvasRuntime`，保存蒙版、笔画、标注、对比图、视图缩放和平移、工具/画笔设置、源图预览返回值及撤销/重做栈。
- 工作区切换先捕获当前画布再恢复目标画布；同一工作区更换图片时重置视图，跨工作区切换保留目标标签自己的视图。
- 运行期画布不进入会话 v2；关闭工作区与“恢复默认但保留 API”会立即释放对应运行态。
- 共享历史图片水合、裁剪和删除会同步修正后台标签持有的对比图与源图返回引用，不把结果写到活动标签。
- 标签关闭门禁覆盖排队、运行、提交中任务和提示词处理；默认按钮为“保留标签并继续”，明确选择“取消任务并关闭”后只取消目标标签的 job、任务和事件订阅。
- 标签状态语义扩展为 `idle`、`queued`、`running`、`prompting` 和 `failed`，并提供对应的无障碍名称。
