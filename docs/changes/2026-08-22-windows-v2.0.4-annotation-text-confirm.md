# Windows V2.0.4 标注文字确认与框外提交

## 修改

- `AnnotationTextEditor` 现在在输入框底部提供亮蓝“确认文字”按钮，使用独立测试标识和无障碍名称。
- 编辑器按钮与外层容器阻止 Konva 事件穿透；按钮按下时阻止默认失焦，避免一次点击产生两次文字历史。
- 交互 Hook 使用编辑状态 ref 获取最新草稿。确认、Ctrl/Cmd+Enter 和画布外点击提交一次文字更新，并将标注工具切换为 `pointer`；点击画布不会继续创建新对象。
- 确认/画布外提交保留空文字对象，显式删除、清空标注和会话取消仍按原语义处理；工具栏操作不被自动切换覆盖。
