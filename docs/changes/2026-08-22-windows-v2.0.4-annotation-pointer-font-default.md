# Windows V2.0.4 标注指针与字体默认值

## 用户问题

文字标注提交后再次调整不方便，工具栏缺少明确的选择入口；固定 `20px` 默认字体在不同自然尺寸的图片上可能过大或过小。

## 实现

- 标注工具栏最左侧新增“指针（选择标注）”。指针模式只操作已有对象，不会在空白处创建新标注；点击文字或带标签箭头会重新打开文字编辑框，点击空白取消选择，确认前可继续修改。
- 指针模式现在支持拖动已命中的标注；矩形、椭圆、线条、箭头、文字、自由画和高亮均按图像坐标整体平移。拖动过程中不会触发文字编辑，纯点击仍保留文字/标签编辑入口。
- 指针命中使用有限的屏幕空间扩散范围：按描边或字体像素与当前缩放计算，约为两倍线宽或 `10px` 屏幕半径；右键命中标注调用现有删除动作并保留撤销能力，空白右键不创建对象。
- 主工具栏的描边/字体滑条现在优先显示当前选中对象的实际样式；未选中对象时显示工作区默认值。修改仍通过现有 `updateAnnotationStyle()` 进入撤销/重做栈。
- 新增 `annotationFontSizeForImage(width, height)`：以标注工作台 4K 临时源最长边按 `最长边 ÷ 64` 计算，并设置 `16px` 下限、沿用 `8–128px` 范围。示例：`480×480 -> 16px`、`1152×1536 -> 24px`、`3840×2791 -> 60px`。
- 自动字体只在当前图片首次准备标注源时初始化；同一张图片离开并重新进入标注工具时保留用户已经调整的值。切换工作区和图片仍按各自运行态隔离。
- Android 不新增指针 UI 或标注交互；共享工具类型仅增加兼容值。

## 未验证风险

- 浏览器控制层对受控 `input[type=range]` 的程序化拖动仍可能只改变原生控件值，字体滑条的最终 Windows Wails 鼠标拖动仍需实机观察；选中对象显示值和更新链路已由代码合同覆盖。
- 真实 Wails DPI、EXIF 方向和不同系统字体抗锯齿继续沿用上一批观察项。
