# macOS V2.0.5 发布封板记录：GPT Image 2.5 与透明 PNG

## 范围

- 基线：`codex/macos-v2.0.4-release` / `2fd097099e11055af18fd82e0e4fc9fc38e80770`
- 开发分支：`codex/macos-v2.0.5-development`
- 发布分支：`codex/macos-v2.0.5-release`
- 只升级 macOS 桌面端、共享前端/Go 客户端和 CLI；不修改 Android、Photoshop 插件、独立 Bridge v1 或历史封板目录。
- 所有自动化使用离线 Mock，不调用真实模型列表、文本优化、图片反推或付费生图 API。

## 模型配置

- 新增 FHL 生图模型配置区，使用第一个已保存的 FHL Images 槽 Key 请求 `/v1/models`。
- 完整列表按上游顺序显示，非目标模型禁用。允许选择的精确 ID 为 Flare、Sunburst、Image 2。
- 选择结果立即写入所有官方 FHL profile，10 个 Images 槽共享。模型列表不持久化。
- 新 profile 保持 `required`；旧 profile 缺少字段迁移到 Image 2；未知已保存模型保留为 `legacy` 并阻止生成。

## 透明链路

- 工作区新增 `backgroundMode=opaque|transparent`，仅 Flare/Sunburst 显示切换。透明强制 PNG；切到 Image 2 或未知模型时恢复 opaque。
- Images generation/edit 请求固定发送透明背景、PNG 和 b64_json。Responses 只在 `image_generation` 工具参数中发送背景和格式。
- 透明请求和带显式 profile 的请求不再静默跨 Images/Responses fallback。
- PNG Alpha 校验要求签名和解码有效、至少一个透明像素、至少一个可见主体像素。失败保留 rawPath，不保存成功图片或历史。
- 背景和 Alpha 状态进入历史、批次任务、JobGroup、CLI JSON 和重试快照。

## CLI 与版本

- CLI 支持 `--background`、`IMAGE_STUDIO_BACKGROUND_MODE`、模型选择状态、Alpha 和脱敏错误字段。
- 新增 `--list-workers`、`--self-test-adaptive`、`--self-test-workflow`，全部是离线合同检查。
- V2.0.5 版本已同步到产品清单、Wails、前端、Go 客户端、CLI、macOS workflow 和 bundle verifier。
- 发布资产名为 `FHL-Image-Studio-Desktop-V2.0.5-macOS-Universal.dmg`、对应源码 ZIP 与 `SHA256SUMS.txt`。

## 安全与发布边界

- `.app` 和 DMG 不包含 API Key、Keychain 数据、用户图片、历史、日志、raw 响应、WebKit 数据或 `cli.env.local`。
- 构建继续使用 macOS 13+、Universal arm64+x86_64、ad-hoc + hardened runtime。
- Gatekeeper 不信任 ad-hoc 未公证包是预期分发限制，不等同于 bundle 或签名结构失败。
- 本轮封板只推送 `codex/macos-v2.0.5-release` 触发候选构建，不创建 `v2.0.5` 标签、不创建 GitHub Release，也不改变 Windows Latest 或其他平台发布状态。
