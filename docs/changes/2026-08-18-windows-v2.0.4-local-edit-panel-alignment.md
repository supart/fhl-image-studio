# Windows V2.0.4 普通图局部编辑面板对齐 360 工作流

## 批次目标

将普通图局部编辑弹窗收窄为与 360 编辑器一致的镜头选区工作台，避免在主编辑区之外重复维护提示词和生成入口。

## 修改范围

- 普通图工作台右侧面板改为“输出管理 / 镜头参数 / 输出 / 工作台”分区。
- 删除弹窗内提示词、AI 优化、风格、单任务生成、外部图片导入和对齐按钮。
- 新增比例横竖切换：`4:3↔3:4`、`3:2↔2:3`、`16:9↔9:16`、`2:1↔1:2`；自由和 `1:1` 禁用方向切换。
- 裁切提交成功后立即清除工作台草稿并回到外部图生图编辑区，原图和局部裁切历史继续保留。
- 旧工作台 `edit/align` 草稿只兼容读取并丢弃，不影响已存在的局部贴回历史；360 查看器和球面算法未修改。

## 开始时的 Git 提交

`3154bb9 fix(local-edit): load full source and improve workbench contrast`

开发分支：`codex/windows-v2.0.4-feature/unified-local-edit-workbench`

## 实现结果

- `LocalEditWorkbenchDraft` 现在只保存来源、自然尺寸、镜头、比例和脏状态，不再携带提示词、分辨率、质量或生成结果状态。
- 普通图保存动作使用自然像素镜头创建唯一局部裁切副本，并关闭工作台；外部主界面的提示词内容不被覆盖。
- 输出管理显示当前来源关联的局部历史缩略图或空态；详情继续走现有历史详情入口。
- 360 标签继续打开现有 `PanoramaViewerModal`，保留输出管理、镜头参数、球面比例、视角和保存并编辑动作。

## 风险与限制

- 本轮未在用户历史上执行真实裁切提交，提交路径由类型检查、合同测试、离线裁切链路和 Store 门禁覆盖；后续如需验收最终历史链路，应使用独立离线夹具。
- 普通图横竖切换只改变裁切比例和镜头框方向，不旋转图像；旋转仍属于后续对齐能力。
