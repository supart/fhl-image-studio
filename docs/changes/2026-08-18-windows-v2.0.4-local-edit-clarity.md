# Windows V2.0.4 局部编辑清晰度与面板可读性修复

## 批次目标

修复普通图局部编辑工作台左侧原图发糊、右侧参数文字低对比和选项截断的问题。

## 修改范围

- 工作台不再优先使用 `media/thumb/...` 缩略图；优先读取受管 `/media/full/...`，没有完整媒体地址时读取 `sourcePath` 原图。
- 全局表单样式不再覆盖工作台控件；右侧选择框和提示词输入统一为深色高对比样式，字号和面板宽度适配 Windows 桌面布局。
- 未修改图像裁切算法、贴回算法、360 球面逻辑、历史数据结构或真实 API 请求协议。

## 实际验证

- 浏览器实测原图自然尺寸：`2048×1360`，不再是 `384×255` 缩略图。
- 右侧“输出尺寸”完整显示 `2K 方形 2048×2048`，提示词文字可读。
- 视口 `1252×930`、`1440×900`、`1024×768` 均无横向或纵向溢出。
- 控制台 warning/error 为 0。
- `npm run typecheck`：通过。
- `npm run test:node`：634/634 通过。
- `npm run lint`：0 errors、58 个既有 warnings。
- `git diff --check`：通过。
- `pwsh -NoProfile -File scripts/dev-check.ps1 -Level Fast`：通过。
- `pwsh -NoProfile -File scripts/dev-check.ps1 -Level Batch`：通过；Node 634/634、UI 107/107、桌面/CLI Go test+vet、Worker 5/5 和离线 smoke check 全部通过。
- 未调用真实或付费生图 API，未修改用户历史记录。

运行 `pwsh -NoProfile -File scripts/dev-check.ps1 -Level Fast` 和 `Batch` 确认门禁后继续普通图局部裁切、外部导入和贴回终态的离线夹具验证。
