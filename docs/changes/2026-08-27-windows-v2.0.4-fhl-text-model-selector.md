# Windows V2.0.4 FHL 文本 API 模型选择

## 范围

桌面版独立 `FHL 文本 API` 配置区现在支持选择 `gpt-5.6-sol`、`gpt-5.5` 或输入自定义模型 ID。该设置只用于 AI 优化、图片反推和对应的 Bridge prompt profile，不改变普通 FHL Responses Profile、FHL Images 池、APIMart、RunningHub 或图像模型行为。

## 默认与迁移

- 新安装或没有已保存 FHL 文本 Key 的环境默认使用 `gpt-5.6-sol`。
- 已有 FHL 文本 Key、但没有模型设置记录的旧环境首次启动迁移到 `gpt-5.5`，保持旧行为。
- 已有模型设置永远优先，不会被启动迁移覆盖。
- 模型 ID 以当前桌面 namespace 的 `image-studio.<namespace>.gptcodex.fhlTextAPI.modelID.v1` 保存；API Key 仍只进入 Keyring。
- 删除专用 FHL 文本 Key 不清除模型选择；完整 API 清空和应用恢复默认会写回 `gpt-5.6-sol`。

## 校验与请求

模型 ID 会去除首尾空格，必须为 `1-128` 个字符且不能包含控制字符。无效自定义值只显示本地错误，不发起测试请求，也不会覆盖上一次有效选择。保存并测试会把当前有效模型发送到 FHL Responses 请求；不支持时保留用户选择并显示包含模型 ID 的错误，不自动降级。
