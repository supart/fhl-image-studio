# Windows V2.0.4 标注变形句柄

## 范围

指针激活后，选中的标注显示轻量变形句柄，不引入第二套画布、Konva Transformer 或新的持久化字段。

- 矩形、椭圆、自由画、高亮：四角拉伸；自由画和高亮按外接框等比映射点列。
- 直线、普通箭头、批注箭头：起点和终点句柄，保持箭头/线条的自然像素几何。
- 文字和箭头标签：四角拖动按自然像素比例调整字号，文字锚点随句柄移动。
- 句柄半径按 `1 / viewScale` 绘制，屏幕上保持可操作大小；命中和更新仍使用图像自然像素。
- 句柄拖动会限制在当前图像边界，所有对象保持最小 `8px` 尺寸或长度；现有整体拖动、右键删除和文字编辑语义不变。

## 实现

- `annotationGeometry.ts` 新增变形句柄、可视外接框和 `resizeAnnotationFromHandle()` 纯函数，兼容旧负宽高和缺失文字尺寸。
- `useAnnotationInteractions.ts` 在指针模式优先识别已选对象句柄，使用原始对象快照计算连续拖动，避免增量漂移；变形拖动不会误触发文字编辑。
- `AnnotationLayer.tsx` 仅在指针模式渲染选中对象句柄；不增加监听层，不影响蒙版、360 或局部编辑。
- `CanvasStage.tsx` 只传递当前选中 ID 和工具值，保持宿主级 Stage/视图坐标转换边界。
