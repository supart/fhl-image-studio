# Windows V2.0.4 设置性能与依赖边界

## 目标与边界

只收敛设置区域的 Zustand 订阅、设置面板生命周期和前端依赖边界，不改变设置字段、存储格式、API 配置、工作区数据或用户操作结果。本批保留 `useStudioStore` 公共入口，不提前拆分 Store、`host.ts`、任务生命周期或 Bridge。

## 实现

- `SettingsPanel` 改用 `useShallow` 精确订阅设置字段、API 摘要、操作函数及 `history.length`，无关 Store 状态不再触发设置面板提交。
- 清空历史时通过 `useStudioStore.getState()` 获取操作瞬间的完整历史，组件只订阅历史数量；同数量的历史内容替换不会重渲染，数量变化仍会更新设置 UI。
- `SettingsPresetsRow` 只订阅预设数组和三个预设操作，不再订阅整 Store。
- `SettingsPanelGate` 在关闭时直接返回 `null`，设置面板真正卸载；从初始化确认等局部子页关闭后重新打开，会回到普通“设置”页并清除局部弹窗状态。
- 删除 `SettingsPanel`、`SettingsPresetsRow` 和已不再整 Store 订阅的 `CanvasStage` ESLint 豁免。整 Store 订阅由 19 处降到 17 处。
- 新增 TypeScript Compiler API 依赖边界测试，解析静态 import/export、动态 import 和 require，精确锁定现有七条反向依赖，禁止 state/lib 新增到 components、app/dev 或 Android Bridge UI 的反向依赖。
- 新增 React Profiler 行为测试，覆盖无关状态零提交、主题更新、同数量/不同数量历史更新和预设变化；新增 Gate 生命周期测试覆盖关闭不挂载、关闭卸载和重开局部状态复位。

现有七条反向依赖基线：

- `state/autoAspectSizing` -> `components/panel/sizeCapabilities`
- `state/materialLibrary` -> `components/history/historyPromptGroups`
- `state/sharedEditAutoAspect` -> `components/panel/sizeCapabilities`
- `state/studioStore` -> `app/dev/previewData`
- `state/studioStore` -> `components/panel/sizeCapabilities`
- `state/studioStore.images` -> `platform/android/bridge`
- `state/studioStore.media` -> `platform/android/bridge`
