## 自动合成收口（2026-08-22）

- 用户确认语义已从“只退出工具”升级为自动栅格化：`确认标注`在离屏 Canvas 上绘制完整原图和全部结构化标注，输出统一 PNG；`批注修图`仍是独立的生图提交入口，不由确认动作触发。

- 标注越界时严格模式返回 `AnnotationCompositeOverflowError`，UI 提供“返回调整”和“扩展白底并保存”。扩展模式按原图与标注联合边界加安全边距生成纯白扩展画布，原图像素不缩放。
- `confirmAnnotationComposite()` 使用捕获的 workspace、当前图和标注快照；按“导入临时 PNG -> 复制到受管 `Output/images` -> 注册媒体 -> 持久化历史 -> 追加 workspace 参考槽”的顺序提交。任何失败、取消、重复点击或工作区切换都会清理临时文件且不写半成品历史/参考槽。

- 浏览器 preview 夹具使用完整 SVG `data:` 原图。原尺寸检查原先仅支持 PNG/JPEG/WebP 二进制头，导致确认动作被错误阻止；现在对完整 Blob 追加 `createImageBitmap`/HTML Image 解码校验，仍禁止把 `previewWidth/previewHeight` 当自然尺寸。

## 实现

- 新增 `frontend/src/features/annotation/`：`annotationTypes.ts`、`annotationGeometry.ts`、`annotationPrompt.ts`、`AnnotationLayer.tsx`、`AnnotationToolbar.tsx`、`AnnotationTextEditor.tsx`、`README.md`。

- `CanvasStage` 仅保留 Stage、图像、缩放/平移、坐标转换和蒙版；标注渲染与绘制预览交给 `AnnotationLayer`。
- 工具栏新增 Cowart 风格颜色盘、笔画宽度、批注修图入口和独立“普通箭头”。普通箭头是工具值 `plainArrow`，持久化为 `arrow` + `bend: 0`，不自动打开标签编辑；Cowart 批注箭头继续自动弯曲和标签编辑。
- 文字改为内联编辑：失焦/`Ctrl/Cmd+Enter` 提交，Escape 取消，空文本删除对象；橡皮擦只删除标注，不改原图像素。
- `submitAnnotationEdit()` 复用现有 edit source、submit、任务队列、失败恢复、历史和结果网格；任务运行或失败保留原图和标注。
- `annotationPrompt.ts` 按创建顺序输出箭头标签/尖端坐标、形状区域、路径边界、高亮区域和文字位置，并固定要求保留未标注区域、移除批注痕迹。
- natural-pixel 入口现在优先读取完整 Blob/Base64、可读取的受管 `fullUrl` 和可信 `width/height`；复用历史图、导入图写入参考槽时保留受管媒体返回的自然尺寸，不再用 `previewWidth/previewHeight` 覆盖它。
- 批注源图准备异常会在本地转为错误提示并清理 in-flight 标记，不向 UI 留下未处理 Promise，也不改变模式、参考槽或批注对象。
