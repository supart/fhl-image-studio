# V2.0.5 Android 模型选择弹层修复

日期：2026-11-10

## 背景

动态 GPT Image 2.x 目录已正确返回多个模型，但统一模型卡片把所有模型项直接渲染在固定卡片的选择区中。模型数量增加后，选项同时出现并互相堆叠，用户无法通过稳定控件选择单个模型。

## 根因

`AndroidFHLImagesPoolConfig` 只有模型快照，没有选择器展开状态；`role=listbox` 和所有 `role=option` 在每次渲染时都常驻。原 CSS 还把列表设为选择区的完整高度，因此模型项共享有限空间。

## 修复

- 增加模型选择器展开状态和 ref。
- 用固定尺寸触发按钮显示当前模型或验证占位，未完成验证时保持禁用。
- 只有点击触发按钮后才挂载 listbox；列表在卡片内部使用绝对定位、最大高度和滚动，不改变下方槽位布局。
- 选中可用模型后保存选择并自动收起；禁用模型保持可聚焦并显示安全原因。
- 面板失活、配置/验证状态变化、刷新开始、Escape 或点击控件外部时收起列表。
- 增加 `aria-haspopup`、`aria-expanded`、`aria-controls`、test id 和静态契约测试，锁定默认收起和事件收起行为。
