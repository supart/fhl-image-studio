# Windows V2.0.4 多图参考上传修复

## 根因与范围

桌面端从参考图槽、workspace、Photoshop Bridge 到 `Service.Edit` 的路径都保留了完整图片数组。实际丢失发生在 `/v1/images/edits` multipart 构造：第一张图片使用 `image`，后续图片使用 `image[]`；部分 FHL 中转只识别重复的 `image` 字段，因此静默忽略了第二张及以后的参考身份。

本批只修改 Windows V2.0.4 当前 Git 开发源码中的 Images API multipart 构造及其浏览器远程回退。Responses API、APIMart、RunningHub、Bridge v1、凭据、图片持久化、Android、V2.0.3 和 Photoshop 插件均不修改。

## 修改

- Go/Wails/CLI 的 `buildEditsMultipart()` 对每张参考图重复使用 multipart `image` 字段。
- 前端远程内核 `buildImagesRequestBody()` 使用相同字段规则。
- 保留图片原始顺序、文件内容、文件名、蒙版以及单图请求行为。
- 更新离线合同测试，验证单图、双图和三图请求均不包含 `image[]`，且三图内容顺序不变。
