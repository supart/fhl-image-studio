# Windows V2.0.4 批次 18A：工作区会话事实源

## 目标

- 让每个标签持久保存自己的活动 Profile、FHL 传输模式和反推图片引用。
- 保留 `useStudioStore` 顶层活动标签镜像，降低后续异步和画布隔离的改动范围。
- 将工作区会话升级为 v2，并安全兼容 v1 数据。

## 实现

- `Workspace` 增加 `activeProfileId`、`fhlTransportMode` 和 `reversePromptImage`；默认字段清单用于防止新增字段遗漏默认值。
- 新标签只继承当前 Profile 与传输模式，提示词、参考图、反推图和任务均为空白。
- 工作区切换同步恢复 Profile 派生运行配置，并异步读取对应 Keyring 凭据；完整 Key 不进入工作区或 localStorage。
- Profile 删除会更新所有引用该 Profile 的工作区；有排队或运行任务时仍拒绝删除。
- 会话载荷版本升级为 2；v1 标签缺失的新字段使用旧版全局活动 Profile 和传输模式迁移。
- 反推图片只持久化稳定路径、名称、大小和安全预览地址，`imageB64`、Blob 与 `memory://` 引用不落盘。
