# Windows V2.0.4 批次 19：Codex 浏览器参考图粘贴降级

## 问题

- 参考图加号和已有卡槽的右键粘贴使用 `navigator.clipboard.read()` 直接读取图片。
- Codex 内置浏览器允许用户触发的原生 `paste` 事件，但拒绝网页主动读取图片剪贴板，因此右键入口只会显示权限错误。
- 全局 `Ctrl+V` 虽然可用，但不能表达“替换当前格”，也无法从右键入口自然继续操作。

## 实现

- 保留支持直接读取剪贴板的原有路径；仅在 API 不可用或权限被拒绝时进入降级，不掩盖空剪贴板和格式不支持错误。
- 新增“粘贴参考图”弹窗，打开后自动聚焦只读接收框；用户触发 `Ctrl+V` 时从原生 `ClipboardEvent` 提取首个 PNG、JPEG 或 WebP 文件。
- 弹窗内的粘贴事件阻止继续冒泡，并且接收框属于输入元素，避免现有全局粘贴监听重复追加同一图片。
- 降级状态保留 `replaceSourcePath`；已有卡槽右键进入时仍按稳定路径替换，目标变化后继续使用既有迟到结果保护。
- 增加本地文件选择按钮；追加和替换复用同一个 `importSourceImageFile()` 入口，不修改工作区格式、媒体路径或导入协议。
- 错误提示只描述权限、空内容或格式，不输出剪贴板数据、图片 Base64 和本地路径。
