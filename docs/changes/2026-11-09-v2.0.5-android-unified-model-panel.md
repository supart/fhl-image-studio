## 实现结果

- “全部活动槽位共同可用的模型”改为始终渲染的固定卡片：常规高度 `190px`，`<=380px` 为 `236px`，状态文字在卡片内部滚动。
- 顶部技术性“获取模型”流程已移除；刷新入口以图标形式放入卡片标题行，普通路径在凭据扫描完成后自动验证。
- 卡片覆盖 `waiting-credentials`、`pending-draft`、`no-targets`、`validating`、`ready`、`error` 六种稳定状态；下拉框和保存按钮在未就绪时保持占位且禁用。
- 自动验证使用不包含 Key 的稳定签名去重，并保留 AbortController、请求版本、凭据 revision 和目标签名守卫；旧结果不能覆盖新配置。
- 成功后只在全部目标槽当前模型均非空且完全一致时预选；不会自动选择第一个模型，也不会自动保存。
- “保存统一模型”是唯一提交入口，继续复用共同目录、Base URL/provider 一致性、原子提交和失败不变更逻辑。
- Keystore 扫描异常不再折叠成“未配置”：卡片进入脱敏错误状态，刷新按钮可重新扫描；API Key 不进入 React 状态、错误正文、日志或证据。
