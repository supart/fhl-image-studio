# Windows V2.0.4 普通图局部编辑镜头框定位

## 批次目标

把普通图局部编辑从“先在主画布画矩形”改为与 360 编辑器一致的“标准比例 + 镜头框定位”工作流。普通图局部编辑直接从工作台开始，原图不被覆盖，360 和整图蒙版保持兼容。

## 修改范围

- `LocalEditWorkbenchDraft` 增加可持久化的单镜头 `LocalEditLens`；旧草稿仍由 `cropRect` 自动兼容。
- `startLocalEditRoundtrip` 无矩形时创建居中 `1:1` 镜头，有矩形时将其转换为自然像素并作为初始镜头，不再切换主画布标注工具。
- 普通图工作台支持自由、1:1、4:3、3:2、16:9、2:1 比例；镜头可拖动、四角缩放、保持比例并限制在自然像素边界内。
- 原图显示框按工作区尺寸和源图比例实时测量，避免横图或竖图出现留白区与镜头框比例不一致。
- 裁切、历史、平面贴回、全景球面流程和 API 请求协议未重写；不保存大图 Base64。

## 开始时的 Git 提交

本批从分支 `codex/windows-v2.0.4-feature/unified-local-edit-workbench` 的工作台提交继续开发。修改前工作区干净，未设置 upstream。

## 实现结果

- 普通图工具栏按钮现在直接打开局部编辑工作台。
- 默认镜头在原图中心创建，当前示例 2048×1360 原图显示为 816×816 自然像素镜头。
- 选择 16:9 后镜头更新为 816×459；拖动和角点缩放均保持屏幕比例与自然像素比例一致。
- 旧的 `cropRect`、工作区刷新恢复和局部贴回历史字段继续保留。

## 风险与限制

- 本批浏览器验收没有点击“确认裁切并编辑”、外部导入或真实生成，以保持用户现有历史不变；这些路径需要在独立离线夹具工作区继续验证。
- 普通图裁切阶段不旋转，旋转仍由现有对齐器处理。
- 单镜头模型暂不支持同一原图同时保存多个局部区域。
