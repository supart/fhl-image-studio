# Windows V2.0.4 清空视图后工具栏保留

## 批次范围

- 分支：`codex/windows-v2.0.4-feature/local-edit-360-parity`
- 仅修改 Windows V2.0.4 画布工具栏；Android、V2.0.3、正式附件、API 配置、历史图片和远程 GitHub 未修改。
- 本批不调用真实或付费生图 API，不创建生成任务，不删除历史或受管图片文件。

## 问题与根因

点击“清空视图”只应清除当前画布，不应让工具入口一起消失。旧实现把工具组、变换组和对比入口都绑定在 `currentImage` 上；清空后 `currentImage` 为空，`BaseToolSection` 还会直接返回空节点，导致用户看不到恢复画布所需的功能入口。

## 实现结果

- 工具组、变换组和对比入口在空画布状态继续挂载。
- 拖动、蒙版、标注、撤销、重做、旋转、翻转、双图对比和卷帘对比在没有当前图片时保持可见但禁用。
- 全屏按钮保持可用；“清空视图”在没有可清空内容时按原语义隐藏。
- 对比按钮仍会检查当前图片和原图来源，不能在空画布状态触发对比。
- 裁出选中矩形也要求当前图片存在，避免删除历史图后遗留的矩形标注在空画布上暴露可用动作。
- 新增 `clearViewToolbar.test.mjs` 合同测试，锁定空画布下的挂载和禁用语义；清空动作和历史/文件数据逻辑未改动。
