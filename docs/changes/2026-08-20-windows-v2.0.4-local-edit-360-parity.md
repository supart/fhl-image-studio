## 审查结论

对照现有 `PanoramaViewerModal` 和 `PanoramaPastebackAlignModal` 后确认：当前 360 数据模型实际只有一个 `shot`，`添加镜头`是覆盖当前镜头，不是可持久化的 `shots[]` 集合。本批只复用 360 的底部工具栏、快照撤销、镜头参数面板、预览和交接模式，不引入多镜头迁移、批量镜头保存或新的球面投影。

## 实现结果

- 普通图工作台增加 360 风格底部工具栏：撤销、重做、重置镜头、清除镜头、展开/收起预览。
- `lensActive` 进入草稿持久化；旧草稿缺失时默认激活。清除镜头隐藏框和预览并禁用两个保存动作，重置按当前比例生成新的居中镜头。
- 镜头几何集中到 `frontend/src/localEdit/lens.ts`，覆盖固定比例中心保持、四角垂直拖动、最小尺寸、自然像素边界和自由比例。
- 预览使用受限 canvas 从源图路径裁切缩略图；不把 Base64 或完整图片写入 React/Zustand/workspace。图片加载失败和 canvas 绘制异常只清空预览，不污染控制台。
- 源图优先使用完整媒体 URL，避免高分辨率图被缩略图放大后发糊；工作区切换时清空撤销栈、重做栈和拖动状态。
- 普通图与 360 模式保持同一工作台外壳；点击“打开 360 编辑器”仍交接到现有球面查看器，历史和贴回算法不变。
- 原生 Wails 与浏览器裁切结果均返回实际宽高并核对镜头尺寸；保存失败、取消、工作区切换或尺寸不一致时清理受管裁切临时文件和 Output 副本。
- 新增受管路径清理能力（Wails `RemoveManagedImage`、浏览器 `/__image-studio-files/remove-image`），仅允许应用托管 `imports` 和 `output/images` 路径。
