# Windows V2.0.4 批注标签独立拖动

## 范围

在“指针（选择标注）”工具下，批注箭头的文字标签可以独立选中和拖动；箭头端点、弯曲和描边不因移动文字而改变。继续使用现有 Konva 画布、自然像素坐标和标注撤销链路，不新增第二套画布或独立持久化系统。

## 实现

- `Annotation` 增加兼容字段 `labelX`、`labelY`。旧数据缺失坐标时，标签继续按箭头起点上方的默认位置渲染。
- `annotationLabelPosition()` 和 `annotationLabelBounds()` 统一提供标签位置与命中边界；标签本身纳入指针命中，命中范围按自然像素字体尺寸限制。
- 指针交互增加标签拖动状态：拖标签只写入 `labelX/labelY`；拖箭头本体时，已经独立定位的标签随箭头同步平移。所有更新仍进入标注撤销/重做快照。
- `AnnotationShape` 与 `annotationComposite` 复用同一标签位置函数，保证视窗预览与最终 PNG 的文字位置一致；越界限制继续使用自然像素边界。
