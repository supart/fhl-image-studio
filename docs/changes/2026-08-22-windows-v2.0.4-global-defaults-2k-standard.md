# Windows V2.0.4 全局默认 2K / 标准

## 根因

普通生成和工作区重置已经使用 `2048x2048`（2K）与 `medium`（界面“标准”），但图生图按源图比例自动适配的批处理配置仍以 `1k` 作为新工作区和缺省恢复值。两个桌面参数面板在用户从手动比例切回自动适配时也会回退到 `1k`，造成同一工作区的默认显示不一致。

## 修改

- 新增共享 `DEFAULT_AUTO_ASPECT_RESOLUTION`，固定为 `2k`。
- 新工作区、旧工作区缺失该字段时的规范化，以及 Windows 桌面/Mac 面板的自动适配回退统一使用该常量。
- 只改变缺省值；用户已经明确保存的 `1k` 或 `4k` 不会被迁移覆盖。
- 质量默认仍为 `medium`（界面“标准”），未改写现有质量选择和历史记录。
- 未修改 Android 的参数默认、上游尺寸映射、V2.0.3、用户图片、API 凭据或真实生图链路。

## 验证

- 定向 workspace runtime 和共享面板合同测试通过。
- 验证通过：typecheck；Node `718/718`；UI 默认模式 `117/117`、单线程 `117/117`；lint `0 errors / 55 existing warnings`；Windows build `1994 modules`；Fast、Batch 和 `git diff --check`。
- Codex 浏览器在 `http://127.0.0.1:5173/?preview=mac-workspace` 的隔离新工作区实测显示 `2K · 标准`；切换图生图后自动适配选中 `2K`，手动切到 `1K` 后保持 `1K`。重载后恢复原始预览状态，新增 warning/error 为 `0`。
