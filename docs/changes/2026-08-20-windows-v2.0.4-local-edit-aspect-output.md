## 需求与决策

普通图“裁切局部重绘”弹窗只负责镜头选区和裁切保存，不复制外部提示词、生成或贴回管理。比例选择必须和主编辑区保持同一套预设、形状预览和下拉交互；保存时区分“保存并编辑”和“保存镜头（不修改）”两种意图。

## 实现结果

### 共享比例选择器

- `LocalEditWorkspaceModal` 复用 `AspectRatioPicker`，预设来自当前 API 的 `aspectPresetsForAPIMode(apiMode, "edit")`。
- `auto` 在局部面板显示为“自由”，不显示重复的英文提示；比例列表包含独立横向/竖向项，不再显示横竖切换按钮。
- 形状预览、listbox、Escape、外部点击关闭和键盘焦点行为保持主编辑区契约。
- 局部菜单通过 portal 定位，避免被双栏弹窗滚动区裁切。

### 两种保存意图

- `LocalEditSaveIntent` 固定为 `edit | lens`，旧 `commitLocalEditWorkbenchCrop()` 继续兼容并默认转发 `edit`。
- 两条路径都读取镜头自然像素矩形，执行源图 `100MP / 16,384px`、编辑/工作内存门禁和 `CropImage`，历史尺寸使用实际裁切宽高。
- “保存并编辑”创建局部裁切副本，切换外部图生图模式和唯一参考图，清空自动比例锁，按当前分辨率同步比例，并把主提示词替换为 `保持构图不变修改画面，将...改为...`；用户随后仍可在外部比例下拉中手动改比例。
- “保存镜头（不修改）”将实际裁切图写入 Output 和历史，替换当前画布，但保留外部提示词、比例、分辨率、质量、模式、参考图槽和批处理配置，不提交生图请求。

### Output 与恢复

- Wails 新增 `SaveImagePathToOutput`，固定复制到受管 `Output/images`，校验图片格式、路径边界和重名；浏览器开发服务使用临时本地 fallback。
- `LocalEditPlanarRoundtripRef.outputPath` 持久化 Output 成果路径；历史导出清理 `sourcePath/outputPath`，不泄露本机路径。
- 保存流程在每个异步阶段重新校验 workspace 和草稿引用，切换标签、取消、刷新或重置后不会提交过期历史。
- EmptyState 中仅有受管路径的导入图在打开工作台前会原子补入历史，避免切换模式后出现“当前没有图片”。
- 原图不覆盖；已有 360 球面入口、整图蒙版和局部贴回终态逻辑保持不变。
