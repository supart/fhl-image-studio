# Windows V2.0.4 工作区异步回写隔离（批次 18B）

## 目标

- 异步操作在 `await` 前绑定发起工作区，完成后只更新该工作区。
- 标签切换不取消后台操作；标签关闭、应用重置或更新请求取代旧请求时，安全丢弃迟到结果。
- 提示词优化和图片反推的运行状态按标签隔离，不再由当前标签共享一个顶层布尔值。

## 实现

- 新增 `WorkspaceActionToken` 注册表，以 `workspaceId`、`workspaceEpoch`、`operationId` 和操作类型验证异步结果；同类操作可显式取代旧令牌，关闭与重置统一失效令牌。
- 提示词优化与图片反推在发起标签保存运行态、结果和错误；两个标签可以并行执行并按相反顺序完成。
- Profile Keyring 读取、参考图/反推图/批处理文件选择、剪贴板与文件导入在异步返回后重新确认原工作区，避免配置或素材写入新活动标签。
- 历史复用、批次图片和大图物化保留共享媒体缓存更新，但只有发起标签可以替换自己的当前画布与来源上下文。
- 旋转、翻转、裁剪和 Windows 画布迟到物化都绑定工作区；原标签关闭或令牌失效后不再加载变换结果。
- 关闭工作区和“恢复默认但保留 API”会清除对应令牌与提示词运行态；不改变全局 API 测试互斥、Profile 定义、Keyring 或任务调度协议。

## 自动化

- 新增令牌纯函数测试：工作区归属、同类请求取代、关闭/重置失效。
- 新增真实 Store UI 测试：双标签提示词优化、双标签反推、双文件选择相反顺序返回、关闭后导入迟到、切换后历史物化迟到、切换后 Profile 凭据迟到。
- 更新旧源码合同，使 Profile 选择必须只写目标工作区的 `activeProfileId`，同时继续保证批次预览不被关闭。
