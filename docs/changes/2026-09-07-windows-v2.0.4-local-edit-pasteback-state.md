# V2.0.4 局部重绘贴回状态修复

日期：2026-09-07  
范围：Windows 桌面版 V2.0.4 Git 开发候选  
分支：`codex/windows-v2.0.4-feature/local-edit-360-parity`

## 根因与实现

- 多图生成结果进入批次网格后，单图画布上的贴回入口不可见；现在每张可确认属于普通局部裁切的最终结果在批次网格和完整历史相册中提供独立的“贴回”菜单。
- 任务 session 压缩仍移除体积较大的 `sourceImages`，但 `BatchTaskRecord.localEditRoundtrip` 在任务创建、重试、浏览器后台、桌面直连、RunningHub 和 APIMart 结果中独立保存并恢复。
- 历史修复按结果/来源嵌套元数据、任务顶层/来源元数据，再按历史 ID 精确匹配或规范化完整路径匹配；不按文件名、尺寸或提示词猜测。历史 ID 不做大小写折叠。
- `HistoryItem.localEditPastebackState="pasted"` 标记自动/手动贴回终态；旧的 `(局部贴回)` 提示仍作为兼容终态标记。终态不再显示重复贴回入口。
- 网格卡片拆为语义外层容器、预览按钮和独立贴回按钮，自动/手动/导入三项继续复用已有 Store、对齐弹窗和文件输入；按钮事件不会穿透卡片选择或双击预览。
