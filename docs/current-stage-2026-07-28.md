# FHL Image Studio 现阶段项目整理

更新时间：2026-07-28

本文记录桌面端、Photoshop 插件、Portable 和 Codex 开发入口当前的真实关系。
它用于开发收尾和新电脑部署判断，不替代每个批次的详细变更记录。

## 产品组成

| 组成 | 当前版本 | 作用 | 当前状态 |
| --- | --- | --- | --- |
| 桌面端源码 | V2.0.3-dev | React 界面、Go/Wails 后端、API 配置、生成队列、输出和 Photoshop Bridge | 最新开发运行版 |

## 已完成能力

### 桌面端

- 继续使用同一套 React 前端和 Go 后端，Wails/WebView2 只提供轻量桌面外壳。
- Portable 不依赖外部浏览器、Node、Vite 或安装程序。
- 支持 1-10 个 FHL Images API 槽，连续生成按当前有效槽调度。
- 普通连续生成保持“一次明确点击只新增一个任务”。
- 重启后旧的排队、运行和提交中任务会标记为中断，不会自动继续产生请求。
- 已修复关闭工作区后不可见孤儿任务被新生成按钮重新唤醒的问题。
- 第一个连续任务会立即显示任务卡；本地启动失败会显示失败卡，不再停在零计数加载状态。
- 新任务和失败任务记录 `FHL1` 到 `FHL10`，方便用户判断 API 分配。
- 空 API 槽刷新后不再执行无意义连接测试或显示整片失败红色状态。
- 保存并测试成功后，在当前没有可用 Profile 时自动选择第一个成功槽。
- 桌面端提供 `127.0.0.1:47631-47640` 的 Photoshop Bridge v1。
- FHL 免费 Images 编辑兼容 Profile 现在正确报告 `supportsMask=false`，插件会使用选区裁切回退；上游 SSE 错误会保留真实原因，明确不支持蒙版时不做重复计费重试。

### Photoshop 插件

- 支持 Photoshop 2023（24.0.0）及更高版本。
- 支持文生图、图生图和选区修改，生成结果作为新图层或按约束替换原图层。
- 异步任务提交时冻结原文档、画布、目标图层、生成边界和完整选区 Alpha 通道。
- 等待期间允许用户取消或重画选区、切换图层和文档，结果仍按提交位置回贴并恢复用户工作焦点。
- 画布坐标变化、原文档关闭或替换目标失效时暂停回贴，不猜测位置；保留结果和锚点供“重新放置”。
- 可选择 V2.0.3 Portable 根目录、保存 Adobe 持久目录授权并启动可见桌面窗口。
- 面板打开时先连接 Bridge；仅在目录有效且本次面板尚未尝试启动时自动启动一次。
- 用户主动关闭桌面端后，五秒重连只更新断开状态，不会不断复活桌面窗口。
- 插件也能连接手动启动的 V2.0.3-dev，但不会把开发版当作可自动启动的正式 Portable。
- 深色面板辅助文字已统一为清晰白色，生成期间按钮显示“运行中…”。

## 当前版本关系

- 当前 Windows 中实际运行的是源码构建的 `FHL Studio 方汤圆版 V2.0.3-dev.exe`。
- Codex 浏览器中的 Wails 开发页和 Windows 桌面窗口属于同一个开发进程，不是两套产品。
- Photoshop 只连接当前占用 Bridge 端口的一个桌面进程。
- 源码版与 Portable 使用相同 Bridge v1 协议，因此插件都能连接；区别是插件自动启动只接受带正确根标记和正式文件名的 Portable。
- 不应同时运行开发版和 Portable，否则可能争用 Bridge 端口并造成配置来源混淆。

## 最后收尾断点

1. 使用当前 V2.0.3-dev 和 Photoshop 2023，手动验收一次真实选区修改：Bridge 应报告 `supportsMask=false`，插件使用裁切回退，任务成功后仍精确回贴冻结位置。
2. 验收通过后，从当前源码在新的隔离目录完整重建 V2.0.3 Portable，不能覆盖任何旧候选。
3. 运行前端、Go、Bridge、插件合同、Package、安全、敏感信息和 SHA-256 校验。
4. 确认最终 Portable 不包含 Node、Vite、Debug EXE、API Key 或已弃用 Skill。
5. 记录最终 EXE/ZIP 大小与 SHA-256，再把新候选提升为插件配套最终桌面版。
6. 用一台干净 Windows 用户环境按零基础安装说明做一次端到端部署验收。

在第 1-5 项完成前，现阶段结论应表述为：Photoshop 插件可交付，桌面端最新源码可用，最终 Portable 尚待最后验收和重建。
