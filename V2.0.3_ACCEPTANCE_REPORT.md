## Image Reverse-Prompt Crash Regression

- The macOS crash report recorded `EXC_BAD_ACCESS`, `Namespace CODESIGNING`, `Code 2`, and `Invalid Page` while executing an anonymous RX page immediately after the reverse-prompt import created an AVIF preview.
- Root cause: `gen2brain/avif` falls back to Wazero when `libavif.dylib` is unavailable. Wazero writes arm64 code into an anonymous RW mapping and changes it to RX, but the app previously enabled hardened runtime without the matching executable-memory entitlement.
- The release signer now validates and embeds the minimal entitlement before producing the DMG. The release verifier reads the signed entitlement back from the final App and fails if it is absent.
- A standalone arm64 backend test binary was signed with the same hardened-runtime options and entitlement; `TestValidateImageBytesAcceptsAVIF` passed without a codesigning termination.
- The rebuilt App then imported a reverse-prompt image, rendered its preview, and completed a live FHL `gpt-5.5` reverse-prompt request. It returned a 413-character Chinese prompt and remained running.
